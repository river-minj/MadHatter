## 5. 퀘스트 체인 플레이테스트 & 완료 흐름 수정

### 발견된 버그
전체 퀘스트 체인(QST_001 → 005)을 순서대로 시뮬레이션하여 두 가지 문제 발견:

**버그 1 — 체인 연결 오류**  
`QST_001._nextQuestId = "QST_002"` 로 설정되어 있었는데, QST_002는 NPC_002(대장장이)가 주는 퀘스트.  
NPCController의 체인 탐색 로직이 `questGiverNpcId != _npcId`이면 중단하므로, NPC_001(이장)을 통한 QST_004 / QST_005 진행이 막혀 있었음.

수정: NPC별 체인을 독립적으로 정리
- NPC_001 체인: QST_001 → QST_004 → QST_005
- NPC_002 체인: QST_002 → QST_003 (독립 종료)

**버그 2 — 퀘스트 완료 흐름 설계 변경**  
기존: 퀘스트 UI에서 보상 버튼으로 즉시 수령 가능  
변경: 목표 달성 후 퀘스트를 준 NPC에게 직접 찾아가야 완료 대화 + 보상 지급  
(맵 어디서든 UI로 보상을 받으면 NPC 완료 대화가 건너뛰어져 몰입감 저하)

### 수정 내용
- `QuestTable.json` — `_nextQuestId` NPC별 재정리
- `QuestManager.TryQuestStart()` — `_dicActiveQuest`에 있고 `_isCompleted=true`이면 completedDialogue 재생 후 `ClaimReward` 호출
- `QuestSlotController` — `_rewardButton` 항상 숨김, 목표 달성 시 진행 텍스트를 "완료! NPC에게 돌아가세요"로 변경
